## 📂 Featured Projects

### ⚙️ [Enterprise ETL Orchestration Platform](https://github.com/Subbham829584/enterprise_etl)
End-to-end data cleaning and ETL platform: upload CSV, Excel, JSON, TXT, PDF or DOCX, clean it automatically, score its quality (0–100, grade A–F) and load it to PostgreSQL.
- FastAPI backend with 11 REST endpoints and an async ORM
- Apache Airflow 2.8 with Celery workers; pipelines defined in YAML and turned into DAGs, so a new pipeline needs no code
- 5-dimension data quality scorer and a 7-page Streamlit dashboard with Plotly charts
- 8 Docker Compose services, 75 automated tests (unit + integration)

`Python` `FastAPI` `Airflow` `PostgreSQL` `Redis` `Docker` `Streamlit` `pytest`

### 🔐 [TaskFlow Pro: Employee & Project Management Backend](https://github.com/Subbham829584/taskflow-pro-complete)
Production-style Spring Boot backend with layered architecture.
- JWT auth with rotating refresh tokens and role-based access (Admin / Manager / Employee)
- Employee, department, project and task modules with filtering and pagination
- RabbitMQ async notifications, Redis caching, WebSocket live updates, Flyway migrations
- Swagger docs, GitHub Actions CI, JUnit 5, Mockito and Testcontainers tests

`Java 21` `Spring Boot 3.3` `PostgreSQL` `Redis` `RabbitMQ` `Docker`

### 📦 [Warehouse Management App](https://github.com/Subbham829584/warehouse_management)
Cross-platform inventory app (Web, Android, iOS) built with Flutter and Cloud Firestore.
- Multi-warehouse structure with nested product groups
- Live stock updates, godown/floor location tagging and real-time search
- Firebase Auth, plus a demo mode that runs without a backend

`Flutter` `Dart` `Firebase` `Firestore`
